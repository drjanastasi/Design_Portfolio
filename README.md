# Design Portfolio — Anastasiia Romashchenko

Сайт-портфоліо продуктового дизайнера. Зроблений на [Astro](https://astro.build), публікуватиметься на Vercel.

- План сайту: [docs/](docs/)
- Дизайн: [Figma](https://www.figma.com/design/mNjWNabXTi7SPBTKxXQVOS/Portfolio-%E2%80%94-Anastasiia-Romashchenko?node-id=6-15)

## Запуск

Потрібен Node.js 22.12 або новіший.

```
npm install
npm run dev
```

Сайт відкриється на http://localhost:4321. Збірка для публікації: `npm run build`.
